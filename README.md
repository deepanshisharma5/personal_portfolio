# Personal Portfolio Website

## About the Project

This project is a responsive personal portfolio website developed using
HTML5 and CSS3. It presents my academic background, technical skills,
projects, achievements, certifications, internships, and contact details
in a clean and user-friendly design.

## Website Sections

- **Home** – Introduction, profile photograph, career objective and navigation
- **About Me** – Interests, career goals and languages
- **Education** – Educational qualifications in a table
- **Skills** – Technical and core skills
- **Internships & Leadership** – Professional experience and leadership roles
- **Projects & Achievements** – Academic projects and achievements
- **Certifications** – Professional certifications
- **Contact** – Email, phone, location, GitHub and LinkedIn
